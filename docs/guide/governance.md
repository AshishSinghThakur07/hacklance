# Admin CMS & Governance

The platform features an administrative console at `/admin` designed for HACKLANCE student council and faculty organizers.

## Authentication Model

- Protected by `AuthContext.jsx` with secure credential verification.
- Session stored in browser storage.
- Demo Administrator Login:
  - **Email:** `admin@hacklance.rrgi.ac.in`
  - **Passkey:** `hacklance2026`

## Management Capabilities

- **Event Lifecycle:** Create, edit, publish, and delete hackathons or workshops with immediate catalog updates.
- **Registration Review:** Audit participant lists, export tickets, and verify student roll numbers.
- **Certificate Issuance:** Generate cryptographically hashed certificates verifiable across the network.
- **Membership Processing:** Review student application essays and skills.
- **Telemetry Reset:** One-click test environment reset to default verified datasets.
